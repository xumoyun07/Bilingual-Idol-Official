# UI/UX Audit — Bilingual Idol Learning Centre

## Retained Brand Foundation

The current interface already establishes a distinctive editorial learning-centre character. The redesign will preserve the following palette and its semantic meaning rather than replacing the brand identity.

| Token | Base color | Existing role | Redesign commitment |
|---|---|---|---|
| Ink | `#10253E` | Hero, footer, high-emphasis actions | Maintain as the structural and navigational foundation. |
| Ivory | `#FBF8F2` | Page surfaces and reading areas | Retain as the calm primary canvas. |
| Apricot | `#F07E5D` | Human warmth, key CTA emphasis | Reserve for language moments, priority actions, and progress. |
| Sage | `#5E8C7B` | Secondary accents and guidance | Use for learning states, successes, and supportive information. |
| Sand | `#E8DCC9` | Borders, grids, layered cards | Use for durable hierarchy without visual heaviness. |

## Current Strengths

The public experience already has strong visual rhythm: editorial serif headings, purposeful multilingual snippets, high-contrast primary actions, and a responsive mobile layout. The Founder login is compact and clear, while the Founder dashboard uses a familiar navigation structure that can grow into a useful operational workspace.

## Friction Points and Redesign Opportunities

| Area | Current friction | Redesign direction |
|---|---|---|
| Learning experience | No unified learner space for timetable, material access, teacher communication, progress, payments, or reports. | Introduce a role-aware learning hub with a single next-action panel and concise task paths. |
| Programme discovery | The empty catalogue is honest but feels operationally incomplete. | Use a structured learning-path navigator and a consultation state that gives visitors a purposeful next step. |
| Founder workflow | Existing dashboard is content-management oriented, but operational learning functions are absent. | Reframe the console around learner health, sessions, payments, reports, and content operations. |
| Mobile density | Long public pages are readable but require extended scrolling to reach the next meaningful action. | Add compact sectional navigation, sticky action affordances, and progressive disclosure. |
| Brand expression | Multilingualism is strongest in the hero and weaker elsewhere. | Make scripts, translation pairs, pronunciation/voice cues, and learning-path signals recurring interface motifs. |
| States and feedback | Empty and loading states are functional but could communicate learning progress more deliberately. | Add expressive yet reduced-motion-safe progress, skeleton, success, and handoff states. |

## Priority Redesign Principle

> The redesigned product should feel like a warm multilingual learning studio in Kuala Lumpur: editorial and premium in the public experience, concise and operational in authenticated spaces, and recognizably Bilingual Idol at every touchpoint.

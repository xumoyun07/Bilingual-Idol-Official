# Moderated usability test protocol

## Purpose

This protocol validates that the minimal frontend supports the real work of a small learning centre. It is an external acceptance activity and cannot be substituted by automated checks. Recruit at least one representative each from a learner or parent, a teacher and a centre staff member. Use designated test credentials and no production personal information.

## Session format

Each moderated session should take 20–30 minutes. The facilitator should ask participants to think aloud, avoid explaining interface labels unless the participant is blocked, and record task completion, hesitation and wording that causes confusion.

| Participant | Task | Success signal |
|---|---|---|
| Learner or parent | Find a relevant programme and identify how to contact the centre | Opens the programme finder, applies or understands a filter, and reaches a contact method without help. |
| Learner or parent | Submit a safe test enquiry | Understands that the enquiry is not a course commitment and completes required fields using non-personal test data. |
| Teacher | Sign in with a test account and identify the available account state | Reaches the correct account space and can return to the public programme list. |
| Centre staff member | Sign in with a test account and navigate to Users, Students and Audit logs | Finds each task from the fixed navigation and recognises the current page. |

## Questions after each task

Ask: “What did you expect to happen?”, “Was anything unclear or unnecessary?”, “What would you change first?”, and “How confident would you be completing this without help?” Record a 1–5 confidence score, observed completion time, error or assistance count and direct quote. Prioritise a change when two or more participants encounter the same barrier or when a task cannot be completed independently.

## Exit criteria

The launch gate is met when every core task can be completed independently by its relevant participant group, no high-severity misunderstanding remains, and the median confidence score is at least 4/5. Any account, personal data or publication action must remain on a designated test record until separately approved.

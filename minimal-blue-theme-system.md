# Minimal Blue Theme System

## Purpose

The public interface should feel like a calm, capable language centre rather than a generic dashboard or a promotional poster. The system keeps the page structure intentionally simple: one clear heading, one supporting paragraph, one primary next action and only factual supporting information per section. The existing user dashboards remain outside this theme pass.

## Visual Language

The theme draws its recognition from the official site’s saturated blue navigation and blue/white logo, but applies it with more restraint. Deep ink carries headings and high-contrast actions; royal blue signals navigation, active controls and accessible focus; mist creates quiet form and supporting surfaces; sand is limited to explanatory callouts. Images remain functional: they establish a learning context, never cover text without a contrast layer, and are not used as decoration below the fold.

| Element | Rule | Practical result |
|---|---|---|
| Page canvas | White, with generous but bounded vertical rhythm. | Reading remains easy on small screens. |
| Section surfaces | Flat white or mist only; 1px blue-gray dividers replace heavy cards and shadows. | The interface looks deliberate without becoming ornamental. |
| Type scale | Display headings use compact tracking and a measured clamp; body text has a comfortable 1.6 line-height. | Public information scans quickly on desktop and mobile. |
| Actions | Royal-blue primary button; ink/white secondary button; text links use an arrow only when they navigate. | One obvious action per decision point. |
| Focus | 3px visible royal-blue outline offset from the control. | Keyboard navigation is unambiguous. |
| Motion | 160ms opacity/transform feedback only; disabled under reduced-motion. | Interactions feel responsive without visual noise. |

## Information Priorities

The Home page foregrounds learning choices and a consultation route. Programme pages can show source-confirmed programme families and 2026 price guidance, but do not present a fee as a checkout commitment. The About page can state that the centre offers language learning informed by learner goals, interactive teaching, digital resources and placement guidance. It does not make uncited performance, approval, premium/luxury or testimonial claims.

## Source-Safe Public Content

The official website remains the contact source of truth: Setapak location, `info@bilingualidol.edu.my` and `+60 3 6731 0449`. The 2026 price list supports a structured price-guidance panel for General English, IELTS, Summer Camp, private lessons and Executive English. The company profile supports the language portfolio and learning-environment principles, but conflicting Pavilion Embassy contact information is deliberately excluded pending owner confirmation.

> The design must never turn unverified source content into a promise. Where dates, availability or contact details require confirmation, the UI directs the visitor to enquiry instead of presenting a transactional claim.

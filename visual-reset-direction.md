# Visual Reset Direction

## Why the First Pass Did Not Read as a Redesign

The earlier version improved polish, but retained the same recognisable pattern: a dark grid hero, a centered top navigation, serif display headline, rounded cards, and alternating dark/light horizontal sections. The result felt like refinement rather than transformation. The new pass must change the **page geometry**, **hero colour dominance**, **navigation rhythm**, and **information grouping**, not merely adjust decorations.

## New Direction: Language Atelier

The visual identity becomes a multilingual **language atelier**: tactile, editorial, and spatially expressive. Ink remains a structural colour, but Ivory becomes the dominant initial canvas. Apricot is used as a large directional surface rather than a small CTA accent. Sage moves into learning-progress and notation details; Sand becomes the material texture that binds section edges.

| Existing visual convention | Visual reset |
|---|---|
| Dark full-width grid hero | Ivory atelier hero with oversized typographic slab, coral language atlas, vertical cue rail, and layered course selector. |
| Centered horizontal sections | Offset split layouts, scroll-like content ribbons, and mixed-height editorial panels. |
| Repeated rounded white cards | Stronger material blocks: soft-paper boards, ink data panels, coral callouts, and narrow annotation cards. |
| Generic multi-page navigation | Contextual “Start here” route plus a compact learning switcher and a bolder Founder utility affordance. |
| Founder operations treated as public cards | Denser “studio desk” layout with task columns, status rail, and clear data-entry regions. |

## Visual Difference Criteria

The new version is accepted only if the following are immediately observable on first view: **the hero begins on a light surface**, **the main title uses a different composition and hierarchy**, **the page uses an asymmetric editorial grid**, **the navigation contains a distinctive language-atelier cue**, and **the Founder area reads as an operational desk rather than a marketing page**.

## Implemented Surfaces

The homepage now opens on Ivory with a coral language atlas rather than a dark grid hero. The learning hub uses a numbered coral learning map and a paper-like content board. The Founder dashboard, operations workspace, and learning-data screen use the same studio-desk motif: dark operational headers, coral working surfaces, stronger geometric edges, and visible status rails. Desktop and mobile visual checks were captured for these four Founder routes and the two public core routes.
